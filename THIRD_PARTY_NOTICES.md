# Source attribution

This repository contains a small, adapted architecture/core subset from the DAWL research code. Network and dynamics files retain their original extraction notes identifying the PNN / SparseDrive-related source lineage.

SparseDrive is MIT licensed; a copy of its notice is included in `third_party/SparseDrive_LICENSE.txt`. This notice does not assign that license to all DAWL-specific code.

No project-wide license has been assigned by this export. No upstream dataset, model checkpoint, credentials, or complete upstream repository is included. The original DAWL experimental archive remains a separate local project.
